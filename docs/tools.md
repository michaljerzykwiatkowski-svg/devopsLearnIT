# Zainstalowane narzędzia DevOps

Lista narzędzi:

- Git - narzędzie do kontroli wersji oprogramowania, śledzenia zmian w plikach. Umożliwia również współpracę kilku osobom nad jednym projektem;
- CURL - narzędzie wiersza poleceń służące do  przesyłania danych za pomocą różnych protokołów (http, https, ftp, etc.);
- WGET - narzędzie wiersza poleceń służące do pobierania plików z internetu. Działa w tle i nie wymaga interakcji;
- UNZIP - narzędzie wiersza poleceń służące do rozpakowywania plików zarchiwizowanych w formacie *.zip;
- HTOP - monitor procesów i zasobów systemowych;
- TREE - narzędzie wiersza poleceń wyświetlające strukturę katalogów w formie drzewa;
- DOCKER - narzędzie służące do tworzenia, uruchamiania i zarządzania aplikacjami w kontenerach;
