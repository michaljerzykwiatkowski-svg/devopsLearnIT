# Zainstalowane narzędzia DevOps i ich krótki opis
1. Zainstalowane narzędzia: 
- Git - narzędzie do kontroli wersji oprogramowania, sledzenia zmian w plikach. Umozliwia rowniez wspolprace kilku osob nad tym samym projektem;
- CURL - narzedzie wiersza polecen sluzace do przesylania danych za pomoca roznych protokolow (HTTP, HTTPS, FTP, itp);
- WGET - jest to narzedzie wiersza polecen sluzace do pobierania plikow z internetu. Dziala w tle i nie wymaga interakcji;
- UNZIP - narzedzie wiersza polecen sluzace do rozpakowywania plikow zarchiwizowanych w formacie *.zip;
- HTOP - monitor procesow i zasobow systemowych;
- TREE - narzedzie wiersza polecen wyswietlajace zawartosc katalogow w formie drzewa;
- DOCKER - narzedzie sluzace do tworzenia, uruchamiania i zarzadzania aplikacjami w kontenerach;
